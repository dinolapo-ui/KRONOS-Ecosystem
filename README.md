# SAGA AI Project

SAGA is an intelligent personal assistant system designed with a hybrid, distributed architecture. Inspired by the vision of a "Jarvis-like" assistant, SAGA aims to automate daily tasks and process data in a modular, highly scalable fashion.

## Core Technologies
Languages: C++, Python
Database System: MariaDB / MySQL
Networking: Socket Programming, TCP/IP, Distributed Node Management

## Architecture
SAGA employs a hybrid dual-approach architecture:
Distributed AI System: Implements a modular design utilizing socket programming and advanced node communication to optimize processing efficiency across networked components.
Travel/Homelab Integration: Engineered for flexibility and portability, allowing the system to scale from local edge-computing environments (Travel Lab) to distributed server clusters (Homelab), ensuring robust performance regardless of deployment context.

## Objectives
Optimized Processing:To construct an AI system capable of operating in a distributed environment to enhance processing efficiency.
Robust Networking: To apply computer networking expertise in managing stable data synchronization between system components.
Hardware-Agnostic Mobility: To maintain system functionality across various hardware setups, from resource-constrained edge devices to powerful workstations.

## Development Roadmap
1. Phase 1: Core Communication Layer - Developing the base socket programming framework for node-to-node data transfer.
2. Phase 2: Modular Logic Implementation 
3. Phase 3: Hardware Portability Testing - Setting up the "Travel Lab" configuration for on-the-go edge computing.
4. Phase 4: Data Persistence & Synchronization - Optimizing MariaDB integration for distributed state management.
